# Borderland Bingo Prototype V1

**This is a front-end prototype only.** Multiplayer, persistence, and Apps Script backend are not connected yet. Room creation, calls, marks, and claims run locally in the browser.

## Run locally
1. Install Node.js LTS from https://nodejs.org/
2. Extract the ZIP.
3. Open the extracted folder in Terminal / Command Prompt.
4. Run `npm install`
5. Run `npm run dev`
6. Open the localhost address printed by Vite.
